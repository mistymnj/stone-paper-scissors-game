Stone-Paper-Scissors Game 🪨📄✂️

📌 Project Description

This is a simple Python-based Stone-Paper-Scissors game where the user plays against the computer. The computer randomly selects a choice, and the program determines the winner based on the game rules.

🎯 Features

- User can choose stone, paper, or scissor.
- Computer selects a random choice.
- Displays both the user's and computer's choices.
- Determines the winner or a draw.
- Checks for invalid user input.

🛠️ Technologies Used

- Python
- Random module
- Conditional statements ("if", "elif", "else")

🎮 Game Rules

- Stone beats Scissor.
- Scissor beats Paper.
- Paper beats Stone.
- Same choices result in a draw.

▶️ How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project in VS Code.
4. Run the Python file using:

python stone_paper_scissors.py

5. Enter your choice when prompted.
